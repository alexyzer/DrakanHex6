# Восстановитель кристаллов

<BlockImage id="extendedae:crystal_fixer" scale="8"></BlockImage>

Восстановитель кристаллов может восстановить Цветущий блок истиного кварца на одну стадию.

Тебе понадобится <ItemLink id="ae2:charged_certus_quartz_crystal" /> и энергия для работы. Щелкните правой кнопкой мыши <ItemLink id="ae2:charged_certus_quartz_crystal" /> для ввода.

Однако, это не может превратить Повреждённый цветущщий блок в Безупречный. Максимальный уровень, которого может достичь Восстановитель кристаллов, — это несовершенный.
