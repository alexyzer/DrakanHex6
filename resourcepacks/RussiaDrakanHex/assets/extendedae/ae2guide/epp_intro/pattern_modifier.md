# Модификатор шаблонов

Модификатор шаблонов инструмент для массовой модификации шаблонов.

<ItemImage id="extendedae:pattern_modifier" scale="4"></ItemImage>

Щелкните правой кнопкой мыши, чтобы открыть графический интерфейс.

## Режим умножения

Вы можете умножить/разделить входные и выходные значения шаблона обработки на x, нажав соответствующую кнопку.

![PM](../pic/pm.png)

Исходный шаблон:

![PM1](../pic/pm1.png)

После x10:

![PM2](../pic/pm2.png)

Кроме того, нажатием кнопки «Очистить» можно очистить все содержимое шаблонов и превратить их в пустые шаблоны.

### Примечания:

- Кнопка деления работает только тогда, когда полученное значение делится на 1. Например, кнопка ÷2 не сработает, если для шаблона требуется 3 булыжника, потому что 3÷2 равно 1,5.

- Кнопка умножения имеет ограничение (999999). Она не может превысить это число для количества одного ингредиента.

## Режим замены

Замените определенный входной и выходной компонент технологического процесса другим элементом.

![PM3](../pic/pm4.png)

В ячейке A будет заменено то, что будет заменено, а в ячейке B — то, чем будет заменен целевой объект.

Например, следующая настройка заменит доску углем.

![PM4](../pic/pm6.png)

![PM5](../pic/pm5.png)

Нажмите кнопку «Заменить», чтобы выполнить замену.

![PM6](../pic/pm7.png)
